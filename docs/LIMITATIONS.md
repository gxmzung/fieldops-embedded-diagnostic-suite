# Limitations

This project is a portfolio simulation and is not intended for production deployment.

Current limitations:

- No real hardware integration yet
- No authentication layer
- No encrypted transport
- Limited test coverage
- Fault scenarios are simulated
- Dashboard is for demonstration only

Future improvements:

- Connect real MCU or sensor board
- Add unit and integration tests
- Add packet validation and replay protection
- Add persistent database storage
- Add deployment guide
